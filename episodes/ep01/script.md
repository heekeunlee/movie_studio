# ep01 — call mom.

- 길이: 약 49초 / 컷 8개 / 대사 없음
- 시간대: 낮(밝은 중성) → 노을(주황) → 밤(스탠드 앰버 + 화면 푸른빛)

## 1. 로그라인
하루 종일 엄마 전화를 뒤집어 놓고 넘기던 남자가 자정 직전 다시 걸고, 엄마는 첫 신호가 끝나기도 전에 받는다.

## 2. 시놉시스
밝은 낮, 노트북 앞에서 일하는 남자의 폰이 책상 위에서 울린다. 화면엔 "mom". 그는 화면을 보지도 않고 폰을 엎어 놓는다.
폰은 엎어진 채로 다시 한 번 떨고, 그는 "busy. call you later" 한 줄만 보내고 일로 돌아간다. 엄마의 답은 짧다. "ok. eat something."
창빛이 노을로, 다시 스탠드 불빛으로 바뀌는 동안 책상 위 화분은 말라 처져 있고, 엎어진 폰은 한 번도 뒤집히지 않는다.
자정 직전, 침대에 누워 화면을 넘기던 그의 엄지가 통화 기록 "mom · 2 missed calls" 위에서 멈춘다. 늦었다는 걸 안다. 그래도 누른다.
신호음이 한 번 채 끝나기 전에 통화 시간이 "00:01"로 바뀐다. 그는 책상 쪽으로 몸을 옮겨, 통화하면서 컵에 남은 물을 말라 있던 화분에 붓는다.
마지막 컷은 첫 컷과 같은 구도 — 책상 위 폰, 이번엔 화면이 위를 향한 채 통화 시간이 흐르고 있다.

## 3. 비트 시트

| 구간 | 컷 | 화면 | 문구 |
|---|---|---|---|
| **0~3초 훅** | C1 (0–3s) | 낮. 책상 위 폰 탑샷, 화면이 위를 향한 채 진동하며 "mom · incoming call". 프레임 밖에서 손이 들어와 화면을 보지도 않고 폰을 **엎어 놓는다**. 진동음만 책상을 타고 계속 | 폰 화면: `mom` / `incoming call` |
| **3~15초** | C2 (3–8s) | 노트북 키보드 위 손, 빠른 타이핑. 옆에 엎어진 폰이 다시 떨고 가장자리로 빛이 샌다. 손이 멈추지 않는다 | — |
| | C3 (8–15s) | 폰을 집어 짧게 문자 입력·전송 → 곧바로 엄마 답장 도착. 그는 읽고 다시 엎어 놓는다. 프레임 가장자리에 마른 흙, 처진 잎의 화분 | 보낸 문자: `busy. call you later` / 받은 문자: `ok. eat something.` |
| **15~35초** | C4 (15–23s) | 고정 앵글, 책상과 창. 빛만 바뀐다: 밝은 중성 → 주황 노을 → 스탠드 앰버. 사람은 같은 자리, 엎어진 폰은 계속 그대로. 화분 잎이 노을 속에서 처져 있다 | 탁상 시계(인서트, 0.5초씩): `2:14 PM` → `6:40 PM` |
| | C5 (23–31s) | 밤. 노트북 덮이는 손. 침대에 누워 폰 스크롤, 화면 푸른빛이 손에만 닿는다 | — |
| | C6 (31–35s) | 폰 화면 클로즈업: 통화 기록에서 엄지가 멈춘다. 1초 머뭇. 탁상 시계 `11:52 PM` 인서트 | 폰 화면: `mom · 2 missed calls` / 시계: `11:52 PM` |
| **35~45초** | C7 (35–43s) | 침대에서 일어나 책상 끝에 걸터앉으며 엄지가 누른다 → `calling...` → 신호음 한 번이 끝나기 전 `00:01`. 어두운 얼굴 1.5초(옆모습, 반쯤 그늘), 짧게 숨을 내쉰다. 폰을 귀에 댄 채 다른 손으로 컵의 물을 마른 화분에 붓는다. 흙이 물을 빨아들인다 | 폰 화면: `calling...` → `00:01` |
| | C8 (43–46.5s) | **C1과 같은 탑샷 구도.** 책상 위 폰, 이번엔 화면이 위를 향함, 스피커 모드, 통화 시간이 흐른다 `04:12 → 04:15`. 스탠드 불빛, 젖은 흙의 화분이 프레임 모서리에 | 폰 화면: `mom` / `04:12` |
| **마지막 문구** | END (46.5–49.5s, 3초) | 검은 화면 단독 | `She was never too busy for you.` |

- **루프:** C8(위를 향한 폰, 통화 중) → C1(위를 향한 폰, 울리는 "mom")로 같은 구도가 이어진다. 다시 보면 첫 컷의 의미가 바뀐다.
- 안전 영역: 폰 화면 문구·폰 본체는 화면 상단~중앙에 배치, 하단 25%·우측 15% 비움.
- 얼굴은 C7의 1.5초만, 어둡게. 나머지는 손·폰·빛·화분.

## 7. 화분 상태
- C3·C4: 흙이 말라 갈라지고 잎이 처짐 — 미룸·정체 (하루 종일 넘긴 전화)
- C7: 통화하며 컵의 물을 붓는 손 — 회복·시작 (signature.md "물 주는 손")
- C8: 젖은 흙, 잎은 아직 처져 있음 — 회복은 이제 막 시작. 과장하지 않는다

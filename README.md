# movie_studio

에이전트 15명이 일하는 **40~55초 시네마틱 쇼츠 제작 스튜디오**. 오피스 화면에서 캐릭터들이 실제 진행 상황대로 움직입니다.

## 본부와 크루

| 본부 | 방 | 크루 |
|---|---|---|
| 📝 기획 | 작가실 | 🔭 트렌드 리서처 · ✍️ 시나리오 작가 · 🔍 표절·정책 검수 · 🎬 감독 |
| 🎥 제작 | 촬영 스테이지 · 사운드 부스 | 📷 촬영감독 · 🖼 키프레임 작가 · 🎞 영상 생성 · 🧊 3D 아티스트 · 🎧 사운드 디자이너 |
| ✂️ 후반 | 편집실 · 상영실 | ✂️ 편집기사 · 🎨 컬러리스트 · 🧐 QA 크리틱 |
| 📈 배포 | 배포 데스크 | 📦 패키징 · 🚀 퍼블리셔 · 📊 데이터 분석가 |

## 흐름
```
리서치 → 시나리오 → 검수 → 샷 리스트 → 프롬프트 → 🔔기획 승인
→ 키프레임 → 클립 (+3D) (+사운드) → 편집 → 컬러 → QA → 🔔최종본 승인
→ 패키징 → 업로드
```

## 단계별 구축

- [ ] 2단계 — 픽셀 스튜디오 오피스 화면
- [ ] 3단계 — ffmpeg 마감 파이프라인 + 첫 편 테스트
- [ ] 4단계 — 생성 API · Blender MCP · ElevenLabs · 업로드 API 자동화
